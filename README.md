# qingting2ets2
此脚本能将[蜻蜓FM](https://www.qtfm.cn/)内的电台转换为能被《欧洲卡车模拟2》（欧卡2）和《美洲卡车模拟》（美卡）所使用的电台文件格式（live_streams.sii），让你在游戏中也能聆听你身边的广播电台！

## 怎么用？
> [!IMPORTANT]
> 此脚本需要Python 3.11或更高版本。

1. [下载](https://github.com/rocky-star/qingting2ets2/raw/refs/heads/trunk/qingting2ets2.py)此脚本到你喜欢的位置。
2. 运行此脚本。
   - **Windows：**双击此脚本的图标即可运行。
   - **Linux：**你可以通过终端运行此脚本（`python3 qingting2ets2.py`），也可以在桌面环境中先为它加上“执行”权限，再打开它以运行。
3. 等待脚本完成。
4. 将产生的live_streams.sii文件复制到合适的地点。

## 复制到哪？
对于Windows：

- 欧卡2：%USERPROFILE%\Documents\Euro Truck Simulator 2\live_streams.sii
- 美卡：%USERPROFILE%\Documents\American Truck Simulator 2\live_streams.sii

对于Linux：

- 欧卡2：$XDG_DATA_HOME/Euro Truck Simulator 2/live_streams.sii
- 美卡：$XDG_DATA_HOME/American Truck Simulator/live_streams.sii
